# Téléchargements

**➜ [Dernière version](https://github.com/Masonnigg/ryacha-releases/releases/latest)**

- Mac avec puce Apple : `…-arm64.dmg`
- Mac Intel : `…-x64.dmg`

Ouvre le `.dmg` et glisse l'app dans **Applications**. Première ouverture : **Réglages Système → Confidentialité et sécurité → Ouvrir quand même**, une seule fois. Les mises à jour se font ensuite dans l'app.

`latest.json` est lu par l'app : ne pas le modifier à la main.
